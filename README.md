# ระบบบริหารคอนเทนต์ (Content Hub)

ระบบวางแผน–ผลิต–อนุมัติ–ตั้งเวลา–วัดผลคอนเทนต์ทุกช่องทางในที่เดียว
เป็นเว็บแอปแบบ static (ไม่มี build step) เปิดใช้ได้ทันที และ deploy ขึ้น Vercel ได้เลย

## ใช้งานได้เลยตอนนี้

เปิดไฟล์ `index.html` ผ่านเว็บเซิร์ฟเวอร์ (หรือเปิด URL ที่ deploy ไว้) ระบบจะเริ่มใน
**โหมดทดลอง** ซึ่งเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนั้น พร้อมข้อมูลตัวอย่างให้ลองกดเล่นได้ทุกหน้า

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## หน้าจอในระบบ

| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวม | KPI, ยอดวิวรายช่อง, จำนวนโพสต์ 14 วัน, คิวที่กำลังจะปล่อย, ประวัติการทำงาน |
| เพจ & ช่อง | จัดการเพจ Facebook / IG / TikTok / YouTube / LINE OA ที่จะส่งคอนเทนต์ไป |
| คอนเทนต์ทั้งหมด | ค้นหา กรองตามสถานะ/ช่อง แก้ไข ทำสำเนา เปลี่ยนสถานะ สั่งตัดคลิป |
| สร้างคอนเทนต์ | เขียนโพสต์ เลือกสไตล์ แนบภาพ/คลิป เลือกช่อง ตั้งเวลา เตือนเมื่อข้อความยาวเกินลิมิตของแต่ละแพลตฟอร์ม |
| แกลลอรี่ | คลังภาพ/คลิปที่ใช้ซ้ำได้ พร้อมแท็ก |
| คลังสไตล์ | เก็บโทนการเขียนที่ใช้ประจำ ให้ทั้งทีมเขียนออกมาเสียงเดียวกัน |
| คิวโพสต์ | ปฏิทินรายเดือน + รายการคิว เลื่อนเวลา/ปล่อยทันทีได้ |
| อนุมัติ | ตรวจคอนเทนต์ก่อนปล่อย อนุมัติหรือตีกลับพร้อมเหตุผล |
| โรงตัดคลิป | ใบสั่งงานตัดต่อ + สร้างคำสั่งพร้อมคัดลอกไปให้ agent ตัดคลิปที่เครื่องคุณ |
| รายงานแสดงผล | บันทึกผลจริงรายโพสต์/รายช่อง ดูยอดวิว อัตราปฏิสัมพันธ์ และประเภทคอนเทนต์ที่เวิร์กสุด |
| ตั้งค่าระบบ | สลับโหมดเก็บข้อมูล เชื่อม Supabase สำรอง/นำเข้าข้อมูล |

## โครงสร้างไฟล์

```
index.html              หน้าเว็บทั้งหมด (ทุกหน้าจออยู่ในไฟล์เดียว สลับด้วย Alpine)
css/app.css             โทนสี ปุ่ม ฟอร์ม กราฟ (ธีมมืด)
js/config.js            ค่าตั้งต้น: แพลตฟอร์ม สถานะ ประเภทคอนเทนต์ คีย์ Supabase (ถ้าจะ hard-code)
js/seed.js              ข้อมูลตัวอย่างสำหรับโหมดทดลอง
js/store.js             ชั้นข้อมูล — ใช้ API ชุดเดียวกันทั้งโหมดในเครื่องและ Supabase
js/app.js               ตรรกะของแอปทั้งหมด
vendor/                 ไลบรารีที่ pin เวอร์ชันไว้ (Tailwind, Alpine, Supabase JS) ไม่พึ่ง CDN ภายนอก
supabase/schema.sql     สคริปต์สร้างตาราง + เปิด RLS ครบทุกตาราง
docs/ROADMAP.md         สิ่งที่ต้องทำต่อ: เชื่อม API แพลตฟอร์ม และต่อกับชุดตัดคลิป
```

## ต่อฐานข้อมูลจริง (Supabase)

1. สร้างโปรเจกต์ Supabase (region: Singapore สำหรับผู้ใช้ในไทย)
2. SQL Editor → วางไฟล์ `supabase/schema.sql` ทั้งไฟล์ → Run
3. Project Settings → API → คัดลอก **Project URL** และ **anon public key**
4. เปิดเว็บ → ตั้งค่าระบบ → เลือกโหมด Supabase → วางค่า → กด "ทดสอบการเชื่อมต่อ" → "บันทึกและใช้งาน"

> สคริปต์ตั้ง policy ให้เฉพาะผู้ใช้ที่ล็อกอินแล้ว (`authenticated`) ถ้ายังไม่ได้ทำระบบล็อกอิน
> จะเชื่อมต่อแล้วอ่านไม่เห็นข้อมูล — แก้ชั่วคราวได้โดยเปลี่ยน `authenticated` เป็น `anon` ในไฟล์ SQL
> แต่อย่าใช้แบบนั้นกับข้อมูลจริง เพราะใครก็แก้ได้

**ห้ามใส่ `service_role key` ในหน้าเว็บเด็ดขาด** — ใช้ได้เฉพาะ anon key และต้องเปิด RLS ทุกตาราง

## Deploy ขึ้น Vercel

เป็น static site ล้วน ไม่ต้องตั้ง build command

```bash
vercel --prod          # หรือเชื่อม repo นี้เข้ากับ Vercel แล้วมันจะ deploy ทุกครั้งที่ push
```

## สิ่งที่ระบบนี้ "ยังไม่ได้ทำ" (พูดตรง ๆ)

- **ยังไม่โพสต์อัตโนมัติ** ไปยัง Facebook/IG/TikTok — ต้องต่อ API ทางการของแต่ละเจ้าก่อน (ดู `docs/ROADMAP.md`)
- **ยังไม่ตัดคลิปเอง** — งานตัดต่อรันบนเครื่องคุณผ่านชุด ii23 edit kit เว็บทำหน้าที่ออกใบสั่งงานให้
- **ยังไม่มีระบบล็อกอิน** — ถ้าต่อ Supabase ให้เปิด Supabase Auth เพิ่ม แล้ว policy ในไฟล์ SQL จะมีผลทันที
