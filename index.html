ที่เก็บข้อมูล

โหมดทดลองเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ถ้าจะใช้งานจริงหลายคน ให้เชื่อม Supabase

⚠️ ใช้ได้เฉพาะ anon key เท่านั้น และต้องเปิด RLS ทุกตาราง — ห้ามใส่ service_role key ในหน้าเว็บ

การจัดการผู้ใช้

เมื่อใช้โหมดนี้ ระบบจะบังคับให้เข้าสู่ระบบก่อน (ตรงกับ policy ที่ตั้งไว้ใน schema.sql)

เพิ่มผู้ใช้ที่ Supabase Dashboard → Authentication → Users → Add user

แนะนำให้ปิด “Allow new users to sign up” ใน Authentication → Sign In / Providers เพื่อไม่ให้คนนอกสมัครเองแล้วเห็นข้อมูลทีม

เชื่อมต่อแพลตฟอร์ม (Facebook / Instagram / TikTok)

การโพสต์อัตโนมัติต้องต่อผ่าน API ทางการของแต่ละเจ้า และ ต้องเก็บ token ไว้ฝั่งเซิร์ฟเวอร์ (Supabase Edge Function) ห้ามเก็บในหน้าเว็บ เพราะใครก็เปิดดูได้

  • • Facebook Page — Graph API /{page-id}/feed ใช้ Page Access Token (ต้องผ่าน App Review: pages_manage_posts)
  • • Instagram — Content Publishing API ต้องเป็นบัญชี Business/Creator ที่ผูกกับเพจ
  • • TikTok — Content Posting API ต้องสมัคร developer และผ่านการรีวิวแอป
  • • YouTube — Data API v3 (upload) ใช้ OAuth ของเจ้าของช่อง
  • • LINE OA — Messaging API broadcast ใช้ channel access token

ดูขั้นตอนที่ต้องทำต่อได้ในไฟล์ docs/ROADMAP.md ของโปรเจกต์นี้
